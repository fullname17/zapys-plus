---

## 1. Что это за продукт

**«Запис+»** — booking/CRM-приложение для бьюти-мастеров (маникюр, барбер и т.п.)
украинского рынка. Планка качества — уровень **Apple / Linear / Stripe / Notion**.

**Бренд (заморожен, не менять):**
- Название: **«Запис+»**. Логотип: **«Галочка+»** (галочка + плюс).
- Дизайн-направление: **Flux × Apple × Stripe** — тёмная тема как основа, акцент
  **iris-purple `#9A9AF6`**, глубина/тени, glass/blur, свечение (glow), плавные
  пружинные анимации, haptic-отклик.
- Локаль: **украинский по умолчанию**; валюта **₴ (UAH)**; таймзона
  **Europe/Kyiv**; демо-данные украинские.
- Пакет: `nova`, bundle `com.nova.app`.

## 2. Стек и архитектура

- **Flutter** + **Riverpod 2.x** + **go_router** + **Drift** (SQLite через
  drift_flutter). Модульная структура ports & adapters:
  `lib/core/`, `lib/data/`, `lib/domain/`, `lib/features/`, `lib/ui/`, `lib/app/`.
- `google_fonts` — шрифт **Inter** в рантайме.
- Дизайн-токены: `KavioColors` / `KavioShadows` (ThemeExtensions, dark-only).
  Класс эффектов `FX` (градиенты / glow / glass / декорации).
- **Виджет-кит `lib/ui/z.dart`** — единая дизайн-система, все экраны собираются из:
  `ZCard, ZHero, ZGlass, ZButton, ZButtonSecondary, ZPill, ZAvatar (с ring),
  ZStatCard (FittedBox), ZSegmented (haptic), ZFreeSlot (пунктир, haptic),
  ZRing, ZLiveRing (анимированное кольцо: пружинная отрисовка + дыхание +
  движущаяся голова), StaggerReveal (карточки выныривают снизу), GlowOrb, ZLabel`.
- Демо-часы `demoNow()` = сегодня **14:20** — для детерминированных скриншотов.
- `bootFragment` снимается в `main()` ДО нормализации URL роутером — оверрайды:
  `?view=day|week|month`, `?step=time|confirm|done`, `?lang=en|ru|uk`, `?hold=1`,
  `?s=1` (пропустить splash-редирект).

## 3. CI-конвейер скриншотов (нестандартный — так проверяется pixel-perfect)

Локального Flutter может не быть (прокси часто блокирует загрузку SDK/шрифтов).
Поэтому сборка и визуальная проверка — через **GitHub Actions**:
- `.github/workflows/web.yml` — сборка web + публикация на GitHub Pages (push в
  рабочую ветку) → живая ссылка для теста в браузере.
- `.github/workflows/shots.yml` — Playwright рендерит экраны в телефонном вьюпорте
  **402×874, DSR 3** и пушит PNG в отдельную ветку `screens`.
- Локально смотреть: `git cat-file blob origin/screens:<name>.png > <name>.png`.
- `tools/shoot.mjs` — список маршрутов; **свежий Playwright-контекст на каждый
  маршрут** (иначе `?query=` не применяется — меняется только hash, `main()` не
  перезапускается).
- CI-бот дозагружает `style: dart format [skip ci]` — при push делать rebase.

**Рабочий цикл:** правка → commit → push → ждать `shots.yml` (~5–11 мин) →
вытащить PNG из `screens` → сверить pixel-perfect → повторить.

## 4. Локализация UK/EN/RU (готово — паттерн держать)

Лёгкий слой `t()` в `lib/core/localization/app_text.dart`:
```dart
String gLang = 'uk';
String t(String uk) { if (gLang=='uk') return uk;
  final m = gLang=='en' ? _en : _ru; return m[uk] ?? uk; }
String tp(String uk, Map<String,Object> args) { var s=t(uk);
  args.forEach((k,v)=> s=s.replaceAll('{$k}','$v')); return s; }
const _en = <String,String>{ 'Сьогодні':'Today', ... };  // ~250 ключей
const _ru = <String,String>{ 'Сьогодні':'Сегодня', ... };
```
- **Ключ = украинский исходник** (uk = identity, безопасный fallback).
- `gLang` ставится в `KavioApp` из локали; `MaterialApp key: ValueKey('app-$lang')`
  перестраивает всё дерево при смене языка (реактивно).
- Переключение: **Меню → Налаштування → Мова** (🇺🇦/🇬🇧/🌐) или `?lang=en|ru`.
- Даты/месяцы/дни недели локализуются в `Fmt` (отдельные массивы uk/en/ru;
  для EN порядок «месяц день»).
- **Принцип:** переводится ТОЛЬКО интерфейс. Данные пользователя (имена клиентов,
  названия услуг из БД, заметки) — НЕ переводить.

## 5. Экраны и фишки (что должно быть)

- **Splash** — анимация «Галочки+» (галочка рисуется по PathMetric, плюс
  выскакивает elasticOut, glow), вордмарк fade-up, слоган «записуй. керуй.
  зростай.» → онбординг.
- **Онбординг** — 3 экрана PageView с живыми превью ценностей, пружинные переходы,
  прогресс-точки, «Далі»/«Почати →»/«Пропустити».
- **Сьогодні (дашборд)** — приветствие, 3 показателя (записи/выручка/окна), герой
  «Наступний клієнт» с ЖИВЫМ отсчётом (ZLiveRing), вільні вікна (пунктирные чипы),
  инсайт возврата клиентов.
- **Календар** — сегменты День/Тиждень/Місяць. День: таймлайн + линия «зараз» +
  вільні слоты. Тиждень: колонки с блоками. Місяць: тепловая карта загрузки.
- **Аналітика** — уровень Stripe/Linear: вкладка «Сьогодні»/Тиждень/Місяць/Рік,
  большие числа с дельтой, area-chart с ghost-линией сравнения, KPI со sparkline,
  heatmap загрузки по дням, топ-услуги.
- **Клієнти** — список с поиском; карточка клиента: аватар с ring, теги
  (Постійна/VIP), следующий запис, быстрые действия (Дзвінок/Написати/Запис),
  LTV-hero, избранные услуги, история, заметки.
- **Послуги** — категории (Манікюр/Педикюр), цветные метки, цены.
- **Підписка** — Старт $3.99 / **Pro $5.99 (Активний, featured)** / Team $7.99.
- **Меню** — профиль, текущий тариф (Free/Pro/Team + статус), группы разделов.
- **Налаштування** — переключатель языка, валюта/таймзона, разделы.
- **Публічна сторінка запису** (`/#/book`) — гостевой флоу в 4 шага
  (послуга → час → контакти → готово), реально создаёт Client+Appointment в БД.
- **Фишки:** Магічний перезапис (на кассе после оплаты — «ходить кожні 3 тижні,
  записати наперед?»), Підсумок дня (evening recap с live-данными), Розумні вікна
  (smart gaps — кого пригласить в свободное окно, с готовым текстом и % прихода),
  shared-element переходы, все микроанимации spring/blur/haptic уровня Apple/Linear.

## 6. Статус

**Готово:** весь v3-UI (все экраны выше), splash+онбординг, все фишки, публичная
страница записи, украинский по умолчанию, подписка в $, **полная локализация
EN/RU** (~250 ключей, проверено на рендерах).

**Осталось — трек «Рабочий застосунок»:**
- Редактирование / отмена / перенос записей (edit / cancel / move).
- Skeletons / shimmer на загрузке.
- Редизайн create-client / create-service шитов до уровня v3
  (create-appointment уже v3).

## 7. Правила работы (важно)

1. Бренд и дизайн-концепцию **не менять**. Видишь, где можно лучше без смены
   концепции — улучшай.
2. **Не упрощать** ни одну анимацию, blur, тени, переходы, взаимодействия.
3. После каждого крупного модуля **показывать реальные экраны** (скриншоты из CI)
   для сверки pixel-perfect с макетами.
4. Полностью украинский интерфейс — без смешения языков.

## 8. С чего начать
1. Подними Flutter-проект `nova` (bundle `com.nova.app`) или продолжи существующий.
2. Заложи дизайн-систему `lib/ui/z.dart` + токены `KavioColors/FX` (§2).
3. Настрой CI web.yml + shots.yml + ветку `screens` для проверки (§3).
4. Собери экраны из §5, сверяя каждый по скриншотам.
5. Продолжай с трека «Рабочий застосунок» (§6).
